# Projeto AquaSense — Landing Page

Desenvolva uma landing page moderna, responsiva e interativa para o **AquaSense**, um produto fictício de monitoramento inteligente de piscinas.

O AquaSense é uma solução que permite acompanhar a qualidade da água de piscinas, monitorando indicadores como pH, cloro, temperatura e turbidez, além de apresentar alertas e recomendações de manutenção.

**Slogan:** "Sua piscina sempre limpa, segura e pronta para uso."

## Tecnologias

- React com Vite.
- JavaScript.
- CSS Modules.
- Arquitetura FSD (Feature-Sliced Design) simplificada.
- Lucide React para ícones.

A aplicação deve ser 100% frontend, utilizando dados mockados, sem backend, banco de dados ou integrações com APIs.

## Identidade visual

Criar uma interface moderna, limpa e profissional, inspirada em plataformas SaaS.

Utilizar uma paleta de cores com predominância de **azul-claro, azul piscina, amarelo e branco**, transmitindo limpeza, frescor, confiança e tecnologia.

### Paleta de cores sugerida

- **Azul-claro (`#4FC3F7`):** cor principal da identidade visual.
- **Azul piscina (`#0288D1`):** botões, títulos e elementos de destaque.
- **Amarelo (`#FFD43B`):** CTAs, detalhes e elementos de atenção.
- **Branco (`#FFFFFF`):** fundos e áreas de conteúdo.
- **Azul muito claro (`#EAF8FF`):** fundos secundários e cards.

## Estrutura da landing page

1. **Header:** logotipo AquaSense, navegação entre seções e botão CTA.
2. **Hero Section:** apresentação do produto, slogan, descrição, imagem ou representação visual do sensor e botão "Experimentar demonstração".
3. **Benefícios:** cards destacando monitoramento inteligente, alertas automáticos, praticidade e histórico de medições.
4. **Como funciona:** apresentação de três etapas: instalação do sensor, monitoramento dos indicadores e recomendações de manutenção.
5. **Demonstração interativa:** dashboard simulado apresentando pH, cloro, temperatura, turbidez e status da água.
6. **Depoimentos:** avaliações fictícias de clientes.
7. **Planos e preços:** três planos fictícios (Essential, Plus e Premium).
8. **FAQ:** perguntas frequentes com accordion interativo.
9. **Footer:** informações do produto e links de navegação.

## Funcionalidades interativas

A principal funcionalidade será um **simulador de monitoramento da piscina**.

Implementar:

- Dashboard com indicadores de qualidade da água.
- Botão para gerar novas leituras aleatórias.
- Sliders para alterar manualmente os indicadores.
- Atualização dinâmica do status dos indicadores.
- Alertas visuais utilizando verde, amarelo e vermelho.
- Recomendações informativas conforme os valores simulados.
- Histórico das últimas cinco leituras.
- Modal simulado ao selecionar um plano.
- FAQ interativo.
- Navegação suave entre as seções.

Os limites dos indicadores são apenas ilustrativos. Não apresentar o simulador como uma análise real de segurança da água.

## Requisitos de desenvolvimento

- Utilizar componentes React reutilizáveis.
- Organizar o código seguindo FSD simplificada.
- Utilizar CSS Modules para estilização.
- Garantir responsividade para desktop e dispositivos móveis.
- Implementar todas as interações utilizando React Hooks.
- Evitar dependências desnecessárias.
- Priorizar código limpo, organizado e de fácil manutenção.
- Garantir que todos os botões e funcionalidades estejam operacionais.
- Não criar backend ou integrações externas.
- Não criar README neste momento.

## Resultado esperado

Uma landing page completa, com identidade visual própria, aparência profissional e navegação fluida.

O principal destaque deve ser o dashboard interativo, permitindo ao visitante experimentar uma simulação do funcionamento do AquaSense.
